# Estimate App (React + Vite)
Local: `npm install && npm run dev`   Build: `npm run build`
Vercel: push to GitHub → vercel.com → Import Project (Framework: Vite, auto-detected), or run `npx vercel`.
Data: saved in the browser (localStorage). Use ⬇ JSON / ⬆ JSON to export / import. Original data: `src/data/*.json`.
Print: 🖨 → browser dialog → "Save as PDF" or choose a network (WiFi) printer. Paper A4, margins: None, Background graphics: on.
Sub Total = Total − Reusable (Credit Materials shown only).
